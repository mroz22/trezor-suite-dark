Suite Dark Source ↗

Unofficial desktop build of Trezor Suite

A Trezor Suite
that keeps to itself.

It is the same Trezor Suite desktop app. It sends Trezor no telemetry and no feedback, takes no remote configuration and shows no promotions. Tor, hidden balances and coinjoin are ready from the first start.

Build it Read every change ↗

Early days. There are no downloads yet, so for now you build it from source. Releases with automatic updates come next.

What is different

Nothing reported to Trezor

Sentry crash reports and analytics are off. That includes the events Trezor Suite sends even after you decline analytics. There is no consent screen, because there is nothing to agree to.

No feedback forms

Ratings, surveys and bug report forms are gone. No free text, device model or firmware version goes to data.trezor.io.

No remote messages

Notices and feature switches come only from the configuration built into the app. It never downloads a newer one.

No promotions

The promo carousel, shop banners, app store badges, Refer-a-Friend and paid surveys are removed.

Tor from the first start

The bundled Tor starts with the app. You do not have to remember to switch it on in Settings.

Balances hidden

Discreet mode stays on until you reveal balances with the eye button.

Coinjoin that runs

Trezor Suite ships without a coordinator since the public ones shut down. Suite Dark mixes Privacy accounts through coinjoin.kruw.io, a public coordinator that charges no coordination fee.

Installs next to Trezor Suite

It has its own app id, settings folder and suitedark:// links, and keeps its data apart from Trezor Suite's.

Dark and orange

The dark theme is the default, in Bitcoin orange. Light and system themes are still in Settings.

What stays the same

Everything else. Every network Trezor Suite supports, Earn, Trading, WalletConnect, NFTs, the experimental password manager and all device features work as they do upstream. Suite Dark is not a cut-down wallet.

What still goes over the network

A wallet needs data. Suite Dark gets it the same way Trezor Suite does, and with Tor on, it sends these requests through Tor.

  • Blockchain data from Trezor's Blockbook servers. You can switch a network to your own Blockbook or Electrum server in its advanced settings.
  • Exchange rates from Trezor's servers.
  • Token definitions and firmware updates from data.trezor.io.
  • The coinjoin coordinator, while an account mixes.
  • Partner services in Trading and Earn, when you use them.

How the fork works

Suite Dark is a GitHub fork of trezor/trezor-suite. Its develop branch is an exact copy of Trezor Suite's. The main branch adds one commit per change and gets rebased when Trezor Suite moves on, so the whole difference fits on one page:

  1. Brand the desktop app as Suite Dark
  2. Stop reporting anything to Trezor servers
  3. Start with Tor and discreet mode on
  4. Remove promotional banners
  5. Mix through the kruw.io coinjoin coordinator
  6. Call the experimental password manager "Password manager"
  7. Default to the dark theme
  8. Keep the local development profile separate
  9. Remove user feedback forms
  10. Document the fork for contributors and agents

Read them on GitHub, or see the full diff against Trezor Suite in one comparison. The reasoning behind each change is in SUITE_DARK.md.

Build it

You need git, Git LFS, nvm and Yarn. The steps follow Trezor Suite's own desktop build. Use macOS or Linux for the build host. 

git clone https://github.com/mroz22/trezor-suite-dark.git
cd trezor-suite-dark
git submodule update --init --recursive
git lfs install
git lfs pull
nvm install
yarn
yarn build:essential
yarn workspace @suite-app/desktop-app build:ui
yarn workspace @suite-app/desktop-app build:app

# then one of
yarn workspace @suite-app/desktop-app build:app:electron --publish never --mac --arm64
yarn workspace @suite-app/desktop-app build:app:electron --publish never --linux --x64
yarn workspace @suite-app/desktop-app build:app:electron --publish never --win --x64

The installer ends up in suite-app/desktop-app/build-electron/. Until releases exist, these builds are unsigned, call themselves Suite Dark Dev, keep their data in a suitedark-desktop-dev folder and do not update themselves.
