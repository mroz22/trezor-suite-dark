Suite Dark

Trezor Suite for desktop with the analytics, crash reports, feedback forms and promotions taken out, and Tor switched on. It's a fork I maintain. The code is Trezor's development branch plus ten small commits.

How to build it See the diff ↗

There are no downloads yet. If you want to try it, build it from source. Signed releases with automatic updates are planned, but there's no date.

What I changed

  • Analytics and Sentry crash reports are off. Trezor Suite sends a few analytics events even after you decline analytics, and Suite Dark drops those too.
  • The rating, feedback and bug report forms are gone, so nothing you'd type into them reaches Trezor.
  • Notices and feature switches come only from the config built into the app. The downside is that you won't see an urgent warning Trezor publishes after your build, so keep an eye on Trezor's announcements.
  • No promo carousel, shop banners, app store badges, Refer-a-Friend or paid surveys. Earn's staking and yield banners are still there, and you can close them.
  • Tor starts with the app, and wallets load only once Tor is connected.
  • Balances start hidden. The eye icon in the sidebar shows them.
  • Coinjoin works again. Trezor Suite ships without a coordinator now, so Suite Dark uses coinjoin.kruw.io, a public coordinator that neither Trezor nor I run. It charged no coordinator fee in November 2026. Mining fees still apply.
  • It's a separate app with its own app id, settings folder and suitedark:// links. Don't run it at the same time as Trezor Suite. Both use the local Trezor Bridge and the same sign-in return port, and both register for bitcoin: links.
  • It starts in the dark theme, in Bitcoin orange.

Everything else is plain Trezor Suite, including every network, Earn, Trading, WalletConnect, NFTs and the experimental password manager. One catch. Links that websites open in Trezor Suite, like WalletConnect links or the Model One recovery page, go to Trezor Suite and not here.

What it still sends

A wallet can't work offline. Suite Dark fetches data from the same servers Trezor Suite does. With Tor on they don't see your IP address, but they do see what you ask for.

  • Blockchain data from Trezor's servers, which see the addresses and accounts you look up. XRP also uses public XRP Ledger servers.
  • Exchange rates from Trezor's servers, which forward some requests to CoinGecko.
  • Token lists, the firmware release list on every start and any newer firmware or language packs, all from data.trezor.io.
  • Trading and Earn data from Trezor's servers. The dashboard and token lists load it even if you never open Trading or Earn. Voting for TRX in Earn sends the vote's transaction ID to Trezor's Earn server before the vote goes out.
  • Your country, looked up at services.trezor.io on Trading and Earn pages, and NFT and dApp images through Trezor's image proxy.
  • Safety checks of WalletConnect requests, Earn deposits and swaps through cdn.trezor.io, and WalletConnect's relay when you connect a dApp.
  • The coinjoin coordinator, about once a minute while you have a Privacy account and more often while it mixes.
  • Dropbox, Google Drive or Suite Sync, if you turn them on.

You can switch a network to your own Blockbook or Electrum server in its advanced settings. Partner checkouts and support links open in your browser, outside Tor, and the app asks before it opens them.

Before you run it

  • It's built from Trezor's development branch, not from releases, so you get changes Trezor hasn't shipped yet.
  • I check the changes myself. There are no automated builds or tests yet.
  • There are no official installers. If someone sends you one, don't run it.
  • Your seed stays on the Trezor. Check addresses and amounts on its screen before you confirm.

How to build it

You need git, Git LFS, nvm and Yarn. Build on the computer you'll run it on, a Mac or a Linux PC, because Yarn installs native modules only for the machine it runs on. If yarn is missing after nvm install, run corepack enable. 

git clone https://github.com/mroz22/trezor-suite-dark.git
cd trezor-suite-dark
git submodule update --init --recursive
git lfs install
git lfs pull
nvm install
yarn
yarn build:essential
cd suite-app/desktop-app
yarn build:ui
yarn build:app

# then the line for your computer
# Mac with Apple silicon
yarn build:app:electron --publish never --mac --arm64
# Mac with Intel
yarn build:app:electron --publish never --mac --x64
# Linux PC
yarn build:app:electron --publish never --linux --x64

The installer lands in suite-app/desktop-app/build-electron/. Until there are releases, these are development builds. They're unsigned, say Suite Dark Dev in the window title, keep their data in a suitedark-desktop-dev folder, don't update themselves and have DevTools on. Like Trezor's own development builds, they use Trezor's development servers for Earn, token lists, Suite Sync and embedded trezor.io pages. Windows builds will come with releases.

How the fork is kept

The repo is a GitHub fork of trezor/trezor-suite. Its develop branch is an untouched copy of Trezor's. The main branch is develop plus these commits, rebased whenever I sync with Trezor:

  1. Brand the desktop app as Suite Dark
  2. Stop reporting anything to Trezor servers
  3. Start with Tor and discreet mode on
  4. Remove promotional banners
  5. Mix through the kruw.io coinjoin coordinator
  6. Call the experimental password manager "Password manager"
  7. Default to the dark theme
  8. Keep the local development profile separate
  9. Remove user feedback forms
  10. Document the fork for contributors and agents

Read them on GitHub or as one diff. SUITE_DARK.md explains why each change is there.
